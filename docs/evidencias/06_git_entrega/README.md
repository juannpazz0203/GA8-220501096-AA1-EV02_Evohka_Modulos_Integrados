# Evidencias de GitHub y entrega

Guardar aquí:

- rama y commit final;
- `git status` limpio;
- enlace o captura del repositorio GitHub;
- inventario documental;
- nombre, tamaño y SHA-256 del APK entregado.

El APK, archivos de firma y respaldos deben permanecer fuera de Git. En la
captura de GitHub no mostrar correos privados, tokens de acceso ni información
de otras cuentas.
