# Evidencias desde la tablet

Guardar aquí capturas saneadas de los flujos Android por rol. Realizar una sola
ronda ordenada con datos ficticios para evitar repetir registros, solicitudes,
contratos o envíos de recuperación.

Antes de capturar:

- activar modo de no molestar;
- cerrar notificaciones y aplicaciones personales;
- comprobar que no haya contraseñas ni códigos visibles;
- utilizar títulos, correos y nombres ficticios;
- verificar que la fecha y el estado mostrados correspondan al caso probado.

No guardar en esta carpeta fotografías privadas sin autorización.
