# Evidencias de MySQL

Guardar únicamente inventarios de esquema, índices, claves foráneas y conteos
agregados. No mostrar filas completas de `usuarios`, contraseñas, hashes,
códigos de recuperación ni datos personales.

Las consultas deben ser de solo lectura. La evidencia final debe confirmar las
diez tablas esperadas y la presencia compatible de RNF03 y
`propiedad_fotos`.
