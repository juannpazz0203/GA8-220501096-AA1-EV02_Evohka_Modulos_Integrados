# Evidencias de backend y API

Guardar respuestas saneadas, inventario de rutas y estado del backend. Una
captura protegida debe mostrar método, ruta, código HTTP y resultado funcional,
pero no el JWT, la cabecera `Authorization`, contraseñas ni cuerpos con datos
personales.

La comprobación pública de estado y una selección mínima de respuestas 200,
401 y 403 son suficientes; no es necesario repetir manualmente todos los casos
cubiertos por las pruebas automatizadas.
